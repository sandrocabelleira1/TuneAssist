# **App Name**: TuneAssist AI

## Core Features:

- File Loading: User interface for loading .BIN and .XDF files, essential for providing the software with the necessary data.
- Map Display: Displays a table representing the ECU map, allowing users to visualize the data.
- Manual Log Input: Enables manual input of test data, which is crucial for calibrating the ECU accurately. There are input fields for RPM, Load, and AFR
- AI Map Correction: Using test data, this tool suggests corrections to the ECU map based on a target AFR. Takes an aggressiveness setting to control how drastic the modifications can be.
- Logging Display: A simple text field is used to visualize important status updates and logs to the user.
- Save Modified BIN: Allows users to save the modified .BIN file, implementing the changes calculated by the software.

## Style Guidelines:

- Primary color: Indigo (#4F46E5) to convey intelligence, insight, and precision.
- Background color: Dark gray (#1F2937), a desaturated indigo, to provide contrast and focus on the content.
- Accent color: Violet (#8B5CF6), an analogous color to indigo, for highlighting interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a clean, modern, and readable interface.
- Use modern, line-based icons for a clean and technical look.
- Implement a modular grid layout for easy content organization and responsive design.
- Incorporate subtle transitions and animations to provide feedback and enhance user experience.
